# Portrait Python

*Python typeset for people who actually have to read it.*

For when your Supposedly Intelligent (SI) coding agent swears on its GPU that the code is correct: **all 227 tests passed.**

It wrote the tests, too. (You haven’t read them either.)

**Now you SERIOUSLY need to read the code.**

Portrait Python gives you aligned values, functions organized into logical paragraphs, and whitespace that makes relationships visible.

An opinionated typesetting spec for humans reviewing code written by suspiciously confident machines.

**Because “all tests passed” is a lovely sentiment, but you’re still opening the file.**
